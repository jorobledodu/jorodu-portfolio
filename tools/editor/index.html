Editor de Proyectos

Editor local para crear proyectos nuevos sin tocar el codigo a mano. Genera un `project.json` compatible con el build del portfolio.

Uso rapido

  1. Rellena el formulario.
  2. O carga un proyecto existente desde el selector.
  3. Anade tags, links y media.
  4. Pulsa en `Generar proyecto`.
  5. Guardalo como `content/projects/<id>/project.json`.
  6. Ejecuta `tools/rebuild-portfolio.bat`.

Notas

  • Este editor es solo local; no forma parte del portfolio publico.
  • Las rutas de imagen, video, PDF o WebGL deben ser relativas al repo.
  • Si existe `portfolioData.js`, el editor avisa si el `id` ya esta en uso.
